wudict Hover

Server

Both the address and the port are configurable in wudict, so this is configuration rather than a fixed value.

Trigger

Searching

Applies to the toolbar search box, the right-click Look up in wudict item and the keyboard shortcut — not to hover, which always uses the popup. The full page has every dictionary, an address bar and history; the popup has three slots and no way out.

Paused sites

Hover lookup is off on these. Pause and resume from the toolbar panel, the icon’s right-click menu, or the keyboard shortcut.

    Lookups

    wudict does not lemmatise, so a word like running is found only if a dictionary stores it. Fallback attempts try apostrophe, possessive, hyphen and suffix variants — each is one more request, but only for a word that would otherwise show nothing.

    Dictionaries

    Leave everything unchecked to let the extension pick automatically — the first capable dictionaries in server order. Order here follows the server.
